Lost your saved tabs? How to recover them, and how to never lose them again

Your tab saver opened to an empty list after a crash, an update or a restart. Here is what to try, in order, with the steps that can make things worse marked clearly.

On this page

  1. Stop: don't uninstall the extension
  2. Look for export or backup files
  3. Check Chrome history and Recently closed
  4. Copy your browser profile folder
  5. Look inside the extension's data folders
  6. Put the recovered links somewhere safe
  7. How to never lose them again

1. Stop: don't uninstall the extension

Uninstalling an extension deletes its storage. If any of your tabs are still on disk, reinstalling to "fix" the extension removes them for good.

Until you have tried the steps below, also avoid:

  • removing and re-adding the extension, or switching to a different one to "start fresh";
  • clearing browsing data (it can remove history you may need in step 3);
  • resetting Chrome's settings or deleting the browser profile.

Disabling the extension is fine if it's misbehaving. Disabling keeps its data.

2. Look for export or backup files

The quickest recovery is a file you already have. Many tab savers can export a list, and you may have done it once and forgotten.

  • Search your Downloads, Documents and Desktop folders for .txt, .json, .html or .csv files from around the time you exported. Searching file contents for http or for a site you know you saved can help.
  • Check the extension's own settings page for a backup, restore or "previous sessions" option.
  • Check cloud folders (Dropbox, OneDrive, Google Drive, iCloud) and email you sent to yourself.
  • If you use system backups (Windows File History, macOS Time Machine, or a Linux backup tool), they may hold an older copy of your browser profile. Restore it to a separate folder, not over your current profile, and continue from step 5.

3. Check Chrome history and Recently closed

A tab saver closes tabs after saving them, but the pages you visited are usually still in your browser history.

  • History: press Ctrl+H (Cmd+Y on a Mac), or type chrome://history in the address bar. Search by site name or keyword, and scroll back to the days you saved the tabs.
  • Recently closed: open the Chrome menu (⋮) and go to History. The Recently closed list can reopen whole windows. Ctrl+Shift+T (Cmd+Shift+T on a Mac) reopens the last closed tab or window.
  • Tabs from other devices: if you use Chrome sync, the History page also lists tabs open on your other devices.

History only contains pages you opened in this browser, and Chrome deletes old entries over time, so this works best for tabs saved recently.

4. Copy your browser profile folder first

The extension's data may still be on disk even when it shows an empty list. Before you look for it, quit Chrome completely and copy the whole profile folder somewhere else, for example into a new folder called tab-rescue on your Desktop. Work only on the copy. Chrome keeps writing to the original, and that can overwrite what you are trying to recover.

Default Chrome profile folder by operating system
SystemDefault Chrome profile folder
Windows%LOCALAPPDATA%\Google\Chrome\User Data\Default
macOS~/Library/Application Support/Google/Chrome/Default
Linux~/.config/google-chrome/Default

If you use more than one Chrome profile, yours may be called Profile 1, Profile 2 and so on instead of Default. To be sure, open chrome://version and look at the Profile Path line.

5. Look inside the extension's data folders

First find the extension's ID: open chrome://extensions, turn on Developer mode, and read the ID (32 letters) on the extension's card. Then, in your copy of the profile folder, look in:

  • Local Extension Settings/<extension-id>/: the extension's local storage.
  • IndexedDB/: look for a folder whose name starts with chrome-extension_<extension-id>. This is the extension's database, if it uses one.

Both are LevelDB databases: folders of .log and .ldb files. They are not meant to be read by people, but URLs are often stored as plain text inside them, and deleted entries can stay in the files until the database tidies itself up later. That's another reason to work on a copy made early.

On macOS or Linux, this pulls every URL out of a copied folder into a text file:

cd ~/Desktop/tab-rescue/Default/"Local Extension Settings"/<extension-id>
strings -n 8 * | grep -Eo 'https?://[^ "<>\\]+' | sort -u > ~/Desktop/recovered-urls.txt

On Windows, open the .log files in a text editor and search for http, or run the same commands in WSL. Expect messy, partial results: some files are compressed, titles may be missing, and you'll see duplicates. It is still often enough to rebuild a list you thought was gone.

6. Put the recovered links somewhere safe

Whatever you recover, save it as a file before doing anything else. Tabhaven can import a plain list of URLs, URL | title text, and JSON files from most tab managers. Paste the list into its Import box and it becomes searchable groups on your shelf, with backup files written immediately.

7. How to never lose them again

Most tab losses have the same cause: the only copy of the list lives inside the browser. Tabhaven, a free open-source Chrome extension, is built so there is always another copy:

  • Tabs close only after the save is confirmed. Every save is a durable IndexedDB transaction, and tabs close only after the write has been committed and read back. If anything fails, your tabs stay open.
  • Automatic backup files. A JSON file and a readable HTML page of links go to Downloads/Tabhaven/, refreshed after every change, plus 7 daily rotating copies. They survive reinstalls, extension ID changes and browser resets, and Tabhaven can import them back.
  • Version history. Every delete, restore, import or edit takes a snapshot first, so you can undo or roll the whole shelf back.
  • Crash-tested on every commit. An automated test kills the browser in the middle of a 5,000-tab write, reloads the extension, restores from the backup files and checks that nothing was lost.

With backup files in place, steps 4 and 5 above are never needed: open Downloads/Tabhaven/, and the HTML file lists every link, readable in any browser.

Keep a copy of your tabs from now on

Tabhaven is free, has no account, and makes no network requests. Everything stays on your computer.
