The problem

Saved tabs are easy to lose

Tab-saver extensions are where many people keep months or years of reading lists, research and half-finished work. Many keep that list in only one place: the extension's own storage inside the browser profile.

When that storage is damaged or wiped, there is often no second copy. Store reviews for tab savers regularly include reports from people who opened the extension after a crash or an update and found an empty list.

Tabhaven was built around one rule: your tabs are never closed until they are safely written, and there is always a copy outside the browser.

  • A crash in the middle of a save leaves the list half-written, and the tabs are already closed.
  • An extension or browser update fails to migrate the stored data.
  • Reinstalling the extension or resetting the browser deletes its storage for good.
  • One wrong click removes a group, with no undo.
How Tabhaven protects your tabs

Four layers, so one failure never costs you your tabs

Each layer covers a different way things go wrong: a failed write, a wiped browser, a mistake, and code changes that would break any of the above.

1 Tabs close only after the save is confirmed

Every save is a durable IndexedDB transaction (IndexedDB is the database built into the browser). Tabhaven waits for the write to be committed, reads it back, and only then closes your tabs. If anything fails, your tabs stay open.

2 Backup files outside the browser

Tabhaven writes backups to Downloads/Tabhaven/: a JSON file and a readable HTML page of links, refreshed after every change, plus 7 daily rotating copies. They survive reinstalls, extension ID changes and browser resets, and Tabhaven can import them back.

3 Version history with undo

Before every delete, restore, import or edit, Tabhaven takes a snapshot. Undo the last change, or roll the whole shelf back to an earlier point.

4 Crash-tested on every commit

An automated test suite runs on every code change. It kills the browser in the middle of a 5,000-tab write, reloads the extension, restores from the backup files, and checks that nothing was lost.

Switching

Bring your tabs over in 10 seconds

Export from the tool you use now, then paste or upload the export into Tabhaven's Import box.

  1. Export from your current tool

    Most tab managers have an export or backup option that gives you text or a JSON file.

  2. Open Tabhaven's Import box

    It's on the shelf page. Paste the text, or upload the file.

  3. Import

    Your tabs appear on the shelf, and the first backup file is written straight away.

Tabhaven reads:

  • OneTab (URL | title text)
  • Session Buddy JSON
  • Tab Session Manager JSON
  • Toby JSON
  • Any JSON file that contains URLs
  • A plain list of URLs
  • Tabhaven's own backup files

Features

Everything a tab saver should do

Save a window in one click

Click the toolbar button. Every tab in the window goes into a named group on your shelf, and the tabs close to free memory.

Restore your way

Open a single tab, a whole group, or a group in a new window. One click each.

Search that keeps up

Search titles and URLs across every group. It stays responsive with 10,000+ saved tabs.

Organise groups

Rename groups. Star a group to keep it at the top. Lock a group so restoring it doesn't remove its tabs. Remove single tabs you no longer need.

Export in four formats

JSON, URL | title text, HTML or Markdown. Your list is never locked in.

Import from other tools

OneTab text, JSON from Session Buddy, Tab Session Manager, Toby and most other tab managers, or a plain list of URLs.

Privacy

Your tabs stay on your computer

Tabhaven has no server to send anything to. Your shelf lives in the extension's local storage and in backup files in your own Downloads folder.

No account Nothing to sign up for.
No server Data stays on your machine.
No analytics No tracking of any kind.
No network requests It never goes online.

The code is open source under the MIT license, so you can check all of this yourself on GitHub. Read the privacy policy.

Install

Install Tabhaven in four steps

Tabhaven is not on the Chrome Web Store yet; the listing is pending. Until it is approved, install it directly from the release file. It takes about a minute.

Download

The latest build of the extension, as a zip file.

Download tabhaven.zip

Get notified of new versions

No email list. Watch the GitHub repo for releases: click Watch, then Custom, then tick Releases.

Firefox

A Firefox version is planned.

  1. Download and unzip

    Download tabhaven.zip and unzip it. Put the unzipped folder somewhere permanent, such as your Documents folder: Chrome loads the extension from that folder, so keep it.

  2. Open the extensions page

    Type chrome://extensions into Chrome's address bar and press Enter. (Browsers don't allow links to this page, so it has to be typed or pasted.)

  3. Turn on Developer mode

    Use the Developer mode switch in the top-right corner of the extensions page.

  4. Click “Load unpacked”

    Click Load unpacked and select the unzipped folder (the one that contains manifest.json). Tabhaven appears in your extensions list. Pin it from the puzzle-piece menu so its button is always in the toolbar.

Updating: download the new zip, replace the contents of the same folder, then click the reload icon on Tabhaven's card in chrome://extensions. If you move the folder instead, Chrome may treat it as a new extension with empty storage. Your backup files in Downloads/Tabhaven/ are still there, and you can import the latest one.

FAQ

Questions

Where are my backups?

In your Downloads folder, under Downloads/Tabhaven/. You'll find a JSON file (for importing back into Tabhaven) and an HTML page of links you can open in any browser. Both are refreshed after every change. There are also 7 daily rotating copies, so you can go back up to a week.

What happens if I reinstall the extension or reset Chrome?

Removing an extension deletes its storage inside Chrome, and a browser reset can too. The backup files in Downloads/Tabhaven/ are ordinary files outside the browser, so they are not affected. After reinstalling, open the Import box on the shelf page and choose the latest JSON backup file. Tabhaven reads its own backup files.

Does it sync between computers?

Not yet. Your shelf lives on this computer. If your Downloads folder is synced by a service like Dropbox or OneDrive, the backup files sync with it, and you can import them on another computer. Encrypted sync is planned.

Is it free?

Yes. Tabhaven is free and open source under the MIT license, and there's no account to create.

Is there a Firefox version?

It's planned. Tabhaven currently runs on Chrome (Manifest V3). Watch the GitHub repo for releases to hear when it's ready.

Why is it not on the Chrome Web Store?

The listing is pending. Until it is published, install from tabhaven.zip using the four steps above.

Which permissions does it need, and why?
  • tabs: to read the titles and URLs of the tabs you save, close them, and reopen them when you restore.
  • storage: to keep your settings in the extension's local storage.
  • unlimitedStorage: so a large shelf isn't cut off by the browser's default storage quota.
  • downloads and downloads.ui: to write backup files to Downloads/Tabhaven/, quietly, without a download notification after every change.
  • alarms: to run the daily backup schedule.
  • contextMenus: to add Tabhaven options to the right-click menu.

None of these are used to send data anywhere. Tabhaven makes no network requests.
