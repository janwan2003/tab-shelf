Click the Tabhaven button in the toolbar, or press Alt+Shift+S, to save every tab in this window here.

Coming from another tab saver?

Export your list there and paste it here. Tabhaven reads "URL | title" lists, JSON exports from most tab managers, bookmark files and plain URL lists.

Reinstalled Tabhaven?

Your backups are still in your Downloads folder. Import Downloads/Tabhaven/tabhaven-backup-latest.json to get everything back.

Import tabs

Paste a list or choose a file: a Tabhaven backup (.json or .html), a "URL | title" text export, a JSON export from another tab manager, a bookmarks .html file or plain URLs (one per line, blank line between groups).

Export

Download everything on your shelf. JSON and HTML files can be imported back into Tabhaven.

Version history

Tabhaven saves a copy of your shelf before every delete, restore, import or edit (the last 30 copies). Restoring a version is itself undoable.
